# Linux Task Automation Platform

The Linux Task Automation Platform is an Operating Systems and Systems Programming project designed to automate frequently used Linux tasks through a simple command-line interface.

## Features

- Interactive task execution
- Linux command automation
- File listing
- Current directory checking
- Date and time information
- Memory usage monitoring
- Disk usage monitoring
- Makefile-based build
- Git repository
- Linux development environment

## Build

make

## Run

make run

## Clean

make clean

## Week 2 Features

- Dynamic command input
- Memory allocation using malloc()
- Automatic buffer expansion using realloc()
- Proper memory cleanup using free()
